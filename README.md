# 伴侶成就系統 | Couple Achievement System

🌐 **Languages / 多語言版本**: [繁體中文](README.md) | [English](README.en.md)

✨ **Online Demo / 線上體驗**: [https://ivanusto.github.io/couple-achievement-list/](https://ivanusto.github.io/couple-achievement-list/)

一個結合 **親密成就打卡**、**關係足跡版圖** 與 **浪漫手帳設計風格** 的伴侶關係檢視與分享卡生成平台。為每一位正在戀愛、同居或結婚的伴侶/夫妻量身打造，幫助檢視關係、增進情趣，讓感情變得更好！

---

## 🌟 核心特色

1. **關係統計看板**: 即時計算伴侶等級（每解鎖 10 個成就為 1 級）與愛情修煉稱號（例如：`🥚 初墜愛河`、`💖 熱戀情侶`、`💬 默契夥伴`、`🔒 信任港灣`、`🔥 激情伴侶`、`🎭 探索先鋒`、`💍 誓言相伴` 到 `♾️ 永恆誓言大宗師`）。
2. **24 大關係領域版圖**: 互動式網格地圖，點擊可標記已達成的關係板塊（包含日常浪漫、心靈契合、激情親密、成人情趣與一生相守五大板塊），並動態計算各領域的探索度。
3. **Canvas 愛情雷達圖**: 原生 Canvas 繪製，無任何外部第三方 JS 庫依賴，完美顯示 5 大關係領域的探索度。
4. **100 項伴侶關係成就**: 包含日常陪伴、精神共識、激情親密、成人探索（含成熟情趣細節）及一生相守等從浪漫小事到終身承諾的里程碑。
5. **10 大榮譽徽章牆**: 自動判定如 `🌱 新手情侶`、`💖 浪漫大師`、`💬 心靈知己`、`🧠 靈魂伴侶`、`✨ 激情愛侶`、`🔥 感官之神` 等徽章解鎖進度（雙階級設計）。
6. **一鍵分享圖卡 (PNG)**: Canvas 自動合成一張包含暱稱、頭像、等級、徽章牆、雷達圖與最引以為傲成就的 800x1200 高解析度個人伴侶成就卡。
7. **雙主題浪漫切換**: 支持極富氛圍的「Deep Velvet Rose (深天鵝絨玫瑰 - 深色)」與「Blush Sakura (暖櫻粉珊瑚 - 淺色)」手帳風格。
8. **備份與還原**: 本地 LocalStorage 自動存檔，並支持匯出與導入 JSON 進度，方便跨裝置同步。
9. **無任何後端**: 完全靜態的單一 HTML 檔案，載入極快，資料 100% 留存在本地端，確保隱私安全無虞。
10. **自訂愛情目標**: 允許伴侶建立最多 10 個兩人專屬的自訂目標並進行勾選，融入分享圖卡中。

## 🛠️ 技術實現

- **核心技術**: HTML5 / Vanilla CSS / Vanilla JavaScript (ES6)
- **圖表/名片生成**: HTML5 Canvas API (動態縮放適應 Retina 螢幕)
- **音效合成**: Web Audio API (程式動態合成音頻 Chime 甜蜜和弦)
- **動態效果**: CSS Keyframes + Canvas 粒子物理系統 (Confetti)
- **本地儲存**: LocalStorage API
- **國際化**: 內建多語系引擎 (i18n)
